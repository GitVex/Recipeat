# Authentication

Login is Zitadel through `nuxt-oidc-auth`. It uses Authorization Code + PKCE, a Web app with no client secret, and `offline_access` so sessions can refresh. The module owns the `/auth/zitadel/*` routes, validates the ID token (access tokens may be opaque), and keeps tokens in encrypted server-side sessions under `.data/oidc`. That directory must be persisted, and it assumes a single instance. Three session secrets, generated separately (`NUXT_OIDC_SESSION_SECRET`, `NUXT_OIDC_AUTH_SESSION_SECRET`, `NUXT_OIDC_TOKEN_KEY` as 32 base64 bytes), must stay stable. Production reads every `.env.example` variable from the runtime environment, with HTTPS redirect URLs that match Zitadel exactly and `NODE_ENV=production`.

A private route sets `Cache-Control: no-store`, calls `requireUserSession(event)`, and takes ownership from `session.claims.sub`, never from the client or an email address. `npm run build && npm run test:auth` runs the production bundle against a mock issuer in Edge.
