# Design

Recipeat looks like a kitchen notebook: warm paper surfaces, olive ink, one terracotta accent, Playfair Display for names (the key word in italic orange) and DM Sans for everything else. Every colour, size, radius, shadow, motion value and font family (`--font-body`, `--font-display`, `--font-hero`) is a custom property on `:root` in `app/assets/main.css`, and the stylesheet uses nothing else; `--olive-*` and `--orange-*` are roles (brand and accent), not hues. A theme is a whole look in `app/assets/themes/<name>.css`: new values for the tokens plus rules of its own, every selector under `:root[data-theme="<name>"]` and on screen only, so printing stays ink on white. It is the `theme` preference (a cookie when signed out), set on `<html>` by the server so the default never flashes, and its fonts load only while it is chosen. Crate Label (#87) is the one there is: a fruit-crate label at night, navy with mustard and crate red, Rye for the hero and Rokkitt for titles, with five print effects (paper grain, stamps, misprinted titles, riso photos, tickets and banners) that an account can switch off one by one, listed in `<html data-plain>`. Its masks and clip-paths never sit on an element with a focus ring of its own; a button's banner shape is a pseudo-element behind it. Photos are printed as a four-ink riso by an SVG filter (`app/utils/halftone.ts`), each on a layer of its own so scrolling does not reprint them; a recipe's source page is never filtered, and `/lab/filters`, reachable only with `NUXT_PUBLIC_LAB=1`, is where filters are tried. In every theme text that is read meets WCAG AA (4.5:1) on `--cream`, `--paper` and `--wash`, which `tests/themes.node.ts` checks; `--faint` is only for things that aren't read, and 7px (`--text-tag`) is only for tags and badges.

The app reads left to right, broad to particular: opening a recipe from `/recipes` folds the list into a rail, and going back reverses it. Movement on the same screen crossfades, moving to another place fades out and in, and overlays rise and sink. Only opacity and transform animate, apart from the collection's columns, and pages never take a transform. Leaving is quicker than arriving (`--dur-exit`/`--dur-enter`/`--dur-move`). All of it is plain Vue `<Transition>`, and reduced motion turns it off.
